# deploy-log

These files are the **author's own deployment records** for one installation (a Debian 13 VM on a Proxmox host): raw command output, dated reports and the acceptance results. They are kept as history, so they contain that installation's host names, addresses and VM numbers.

- [test-results.md](test-results.md) is the live acceptance status (Current status table) with its history below.
- Files with a "Snapshot as of" banner are immutable; later corrections are appended as dated "Correction" sections.
- You do not need any of this to install or use TimeCanvas. Start at the [README](../README.md).

For publication (2026-11-23) the raw host dump was removed and addresses, MAC and local paths in these records were replaced with placeholders such as `<vm-lan-ip>`; times and results are unchanged.
